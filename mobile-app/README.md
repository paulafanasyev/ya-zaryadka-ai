# Я-Зарядка AI (Android)

Детское приложение для утренней зарядки (4–16 лет). Тренер Пико следит за движениями через камеру и подсказывает голосом и субтитрами.

## Что есть в сборке 0.2.0

- Заставка, знакомство (имя, возраст, согласие родителя на камеру).
- Зарядка: 4 программы, 10 упражнений. Распознавание позы MediaPipe Pose Landmarker работает на телефоне, видео не записывается и не отправляется.
- Подсчёт повторов, проверка кадра (нет человека, слишком близко или далеко, несколько людей, темно), подсказки Пико с интервалом из настроек (по умолчанию 8 секунд), голос через Android TTS.
- Результат: Точность, Меткость, Кучность, начисление Сердец, 10% в Копилку.
- Вознаграждения: цели, Копилка, Молнии (1% в неделю), обмен Молний, запросы родителю.
- Добрые дела и привычки, Учёба и творчество (подтверждает родитель).
- Родительский режим с PIN-кодом, автоблокировка через 15 минут.
- Меню: Баланс, Профиль, Информация, Настройки, Поделиться, О приложении.

## Ограничения тестовой сборки

- Данные хранятся только на телефоне. Сервер и синхронизация семьи ещё не подключены.
- Модель распознавания загружается из интернета при первом запуске зарядки.
- QR-код, Поддержка и покупка у партнёров пока недоступны.
- APK подписан отладочным ключом. Для RuStore нужен релизный ключ.

## Сборка

APK собирается в GitHub Actions: workflow `Android APK` (`.github/workflows/android-apk.yml`).

Локально:

```bash
cd mobile-app
mkdir -p assets
curl -fsSL -o assets/pico.png https://raw.githubusercontent.com/paulafanasyev/ya-zaryadka-ai/main/assets/robot/robot_3Dblue.png
npm install --legacy-peer-deps
npx expo install --fix
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease
```
